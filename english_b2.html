Study block schedule

7 часов/нед, без пересечения с работой и дорогой.

Повторяется каждую неделю

Сб 11:00–13:00Тема недели + глубокий грамматический блок
Вс 15:00–17:00Reading / Use of English + заметки
Вт 19:30–21:00Listening + shadowing / pronunciation
Чт 19:30–21:00Writing / speaking + недельное закрепление

Логика нагрузки

Будние блоки начинаются не раньше 19:30, то есть после дороги домой. Самые тяжёлые задачи вынесены на выходные; будни используются для более узких навыков.

Если неделя перегружена, минимальная версия = Сб + Вс + один будний блок = 5,5 ч. Целевая = все четыре блока = 7 ч.
